# @callstack/example-additional-project-root-2

This is a test package for the needs of example tester projects in this monorepository. None of them depends on it, but the bare and Expo examples pass it as a second additional project root (`additionalProjectRoots` / `--additional-project-roots`), next to `@callstack/example-additional-project-root`, to test that the licenses of the dependencies of several additional project roots (`clsx`) are included in the report.
